# TuCasa V2

Mobile-first TuCasa web app using Vite, React and Supabase.

Core V2 loop: username/password account creation, Discover, progressive party creation, Public/Approval/Code/Private access, invite links and QR, live party membership, a Snapchat-style camera, collaborative photo/video Dump, and a home-screen installation prompt.

Username-first signup is implemented by the username-signup Edge Function using a server-side synthetic Auth email until a real email is added.
